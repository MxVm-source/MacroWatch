# JJ briefing implementation plan

Goal: deliver the approved private Telegram JJ information filter on the existing Render worker.
Architecture: deterministic source adapters, persisted deduplication and source health, scheduler integration.
Tech stack: Python, requests, APScheduler, exchange_calendars, unittest.
Spec: docs/superpowers/specs/2026-11-06-jj-design.md

## Constraints and review focus
Private destination only; no AI-created numbers; timestamps aware; official source dates checked against event dates; outages cannot become quiet-day claims; dedup survives restart; only successful sends marked; holiday/weekend sessions handled; unsupported outcomes labeled unavailable; no added paid services.
